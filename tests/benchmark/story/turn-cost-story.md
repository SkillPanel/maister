# Turn-cost story — node prose

## `intake`

Write `analysis/intake.md`: the topic in one sentence, nothing else. Read no project file.

## `context`

Write `analysis/context.md`: one sentence on where the topic sits in the project. Read no project
file.

## `locate`

Dispatch the delegate once, asking for the files that define the topic, at "quick" breadth.
Write `analysis/places.md`: the paths it returned, one per line, at most five.

## `wrap`

Write `outputs/summary.md`: three lines — the topic, how many places were listed, whether the
probe's findings were settled.
